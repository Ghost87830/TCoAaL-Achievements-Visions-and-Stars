# TCoAaL-Achievements-Stars-and-Visions
## Quick method for the achievement hunters out there ;-)

Add and delete save files from ```%appdata%\CoffinAndyLeyley``` **DO NOT DELETE ```global.rpgsave``` OR ```config.settings```**

If you notice that making changes to that folder does not affect the game go to steam > Properties > General > Steam Cloud and disable 'Keep game saves in cloud'

Download the .rpgsave files that you need and rename them to fit in empty slots :-)

Use the vision unlock folder first - All you will need to do is load into the save folder and interact with the kart
